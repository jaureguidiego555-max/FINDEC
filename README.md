## Uso
Abrir index.html en el navegador. Seleccionar compra, alquiler o venta, ingresar datos y evaluar. La tasa debe corresponder al periodo seleccionado. Los flujos se descuentan al cierre de cada periodo. No incluye financiamiento ni impuestos adicionales.

## GitHub Pages
Subir index.html y README.md directamente a la raíz del repositorio. En Settings > Pages seleccionar Deploy from a branch, main, / (root), Save. Esperar la publicación y abrir Visit site.
